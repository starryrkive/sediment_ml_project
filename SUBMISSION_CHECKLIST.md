# Submission checklist

- [ ] Replace `data/demo_synthetic_data.csv` usage with the actual dataset in `data/sediment_data.csv`.
- [ ] Run `python src/train_models.py --data data/sediment_data.csv`.
- [ ] Check `outputs/model_results.csv`.
- [ ] Check all four prediction plots.
- [ ] Put your names, section and course in the PPT and write-up.
- [ ] Update the write-up Results section with YOUR actual results.
- [ ] Do not upload restricted/private raw data to GitHub.
- [ ] Make GitHub repository private.
- [ ] Add faculty/TAs as collaborators.
- [ ] Make sure README explains setup and run commands.
- [ ] Rehearse the 30-second explanation and the Q&A slide.
